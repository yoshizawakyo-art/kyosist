# サブエージェント選択ガイド（Codex）

Codexでは、サブエージェントは「明示的に委譲が必要なとき」だけ使う。  
標準はメインエージェントで実装し、並列化価値が高い場合のみ委譲する。

## タスク別の使い分け

- コード探索・依存調査: `explorer`
- 実装作業（分割可能な独立タスク）: `worker`
- 軽微な単発修正: メインエージェントで対応
- 仕様判断や最終責任が必要な判断: メインエージェントで対応

## 選択原則

1. 直近のクリティカルパスはメインエージェントで進める
2. 非依存タスクだけをサブエージェントへ委譲する
3. 同じ成果物を重複して作業しない
4. 変更ファイルの責務を明確に分離する

## 推奨パターン

- 調査並列: `explorer` を複数起動して独立した質問を並列実行
- 実装並列: `worker` を機能単位で分割（ファイル責務が重ならないようにする）
- 最終統合: メインエージェントが差分確認・整合性チェックを実施

## 禁止パターン

- 指示が曖昧なまま委譲する
- メインエージェント自身がすぐ必要な結果を丸ごと委譲して待機する
- 同一ファイルを複数workerに同時編集させる
