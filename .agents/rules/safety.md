# 危険コマンド警告プロトコル

以下に該当するコマンドは、**いかなるモード（Auto/Manual問わず）でも必ずユーザへの警告と明示的な承認を取得してから実行する**。
絶対に自律実行しない。

## 危険コマンド一覧

### 広範囲なファイル削除・破壊
- `rm -rf /` / `rm -rf /*` — システム全体のデータを強制削除
- `rd /s /q C:\` — Cドライブの全データを警告なしで削除
- `rm -rf .*` — `.git` や `.env` を含む全隠しファイルを削除

### 権限の無差別な解放
- `chmod -R 777 /` / `chmod -R 777 .` — 誰でも読み書き実行可能に変更
- `chown -R root:root /` — 全ファイルの所有者を強制変更

### 外部コードの無条件実行
- `curl ... | bash` / `curl ... | sh` — ネット上のスクリプトを内容確認なしで即実行
- `wget ... | bash` — 同上

### ディスク・パーティションの直接操作
- `dd if=/dev/zero of=/dev/sda` — ストレージをゼロ上書きし物理消去
- `mkfs.*` を既存パーティションに対して実行 — 強制フォーマット

### リソース枯渇（システムクラッシュ）
- `:(){ :|:& };:` （Fork爆弾）— プロセスを無限複製しシステムをフリーズ

## 警告フォーマット

危険コマンドを実行しようとする場合、以下の形式でユーザに提示する:

```
⚠️ 危険なコマンドを検出しました

コマンド: <コマンド>
リスク: <何が起きるか具体的に説明>
対象範囲: <影響を受けるファイル・システム>

このコマンドを実行してよいですか？（yes と入力して承認）
```
