# Quick Form Filler

フォーム入力を自動化します。JavaScriptを使用します。

## 概要

このスキルはフォームを埋めます。複数のフィールドに対応しています。

## 手順

1. まず、フォームを見つける
2. データを用意する
3. 入力する
4. 送信する

## 使用例

```javascript
// ユーザーが書くコード
fillForm(data);
```

## その他

このスキルは最新ブラウザで動作します。古いブラウザは対応していません。パフォーマンスは環境に依存します。

## トラブルシューティング

エラーが出た場合は、ブラウザのコンソールを確認してください。
