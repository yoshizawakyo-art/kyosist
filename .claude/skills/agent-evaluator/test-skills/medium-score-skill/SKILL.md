# Data Organization Skill

## 目的

複雑で整理されていないデータを構造化する。

## 使い方

ユーザーがデータを提供して「このデータを整理して」と言う場合、このスキルが役立ちます。

```
/organize-data "ここにデータを貼り付ける"
```

## ワークフロー

### ステップ1: 入力を受け取る
ユーザーからデータを受け取ります。

### ステップ2: 分析する
データの構造を分析して、どう整理すればいいか考えます。

### ステップ3: 整理する
データを整理して、見やすい形式に変換します。

### ステップ4: 出力する
整理されたデータをユーザーに返します。

## 例

**入力:**
```
田中 30 東京
鈴木 25 大阪
佐藤 35 京都
```

**出力:**
構造化データ（CSV/JSON形式など）

## トラブルシューティング

データが不正な形式の場合は、エラーメッセージを返します。
