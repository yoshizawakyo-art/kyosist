| `last_seen_at` | `timestamptz` | NOT NULL | Last activity timestamp |

| `updated_at` | `timestamptz` | NOT NULL | Update timestamp (auto) |

#### Constraints
- **CHECK**: `expires_at > created_at` — Prevents invalid expiration dates
- **CHECK**: `revoked_at IS NULL OR revoked_at >= created_at` — Prevents backdated revocations
- **FOREIGN KEY**: `user_id` → `users(id)` with `ON DELETE CASCADE`
